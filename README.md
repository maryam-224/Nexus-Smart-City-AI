# 🏙️ Nexus Smart City: Comprehensive AI Core & Navigation Suite

A comprehensive Artificial Intelligence Jupyter Notebook project simulating a dynamic urban infrastructure. The system leverages search strategies, evolutionary computation, game-theory threat evaluation, and probabilistic reasoning to optimize city navigation, emergency response, power grids, and cyber security.

---

## 📌 Features & Algorithms Implemented

- **Universal Search Engine Suite:** Comparative evaluation of Uninformed (`BFS`, `DFS`, `DLS`, `IDS`, `UCS`) and Informed (`A* Search`, `Greedy BFS`) algorithms with dynamic traffic and weather modifiers.
- **Vehicle Route Tour Planner (Genetic Algorithm TSP):** Population-based evolutionary optimization for Travelling Salesperson Problems across city landmarks.
- **Cyber-Attack Mitigation (Alpha-Beta Pruning & Expectiminimax):** Adversarial search and probabilistic threat evaluation for network firewall security.
- **Local Grid Optimization (Hill Climbing):** Tactical local search heuristics for dynamic rerouting and junction management.
- **Logic & Knowledge-Based Systems:** Propositional logic engine and autonomous Wumpus-style environment exploration.
- **Dynamic Telemetry & Visualizations:** Real-time matplotlib urban grid mapping, congestion heatmaps, and metric comparison dashboards.

---

## 🛠️ Project Structure

- `nexus_smart_city.ipynb`: Complete executable Jupyter Notebook containing graph definitions, routing engines, heuristic functions, security modules, and interactive console menu systems.
